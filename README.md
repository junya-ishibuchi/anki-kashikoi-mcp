# Anki Kashikoi MCP Server

A Model Context Protocol (MCP) server for Anki flashcard management, distributed as a Desktop Extension (DXT).

## Prerequisites

- Anki running with [AnkiConnect addon](https://ankiweb.net/shared/info/2055492159)
- MCP-compatible AI application supporting DXT extensions

## Installation

1. Download the `.dxt` file
2. Install in your AI application following its extension installation process
3. Ensure Anki is running with AnkiConnect addon
4. The server automatically connects to AnkiConnect at `http://localhost:8765`
